# Sucheth ASUS TUF Gaming results

The phase8-style report, CSVs, and `fig_e2e_vs_size.png` / `fig_execution_speedup.png` come from the quick run on `dataset.csv`; the original run files are in `results/sucheth-katte-ASUS-TUF-Gaming-F15-FX507VU-FX507VU/`.

The `fig_bursts.png`, `fig_floor_ratio.png`, `fig_parallelism_vs_size.png`, and `phase6_summary.md` files are the project's shared Phase 6 Ethereum analysis, copied here for convenient access. They are based on the Phase 6 corpus and are not measurements specific to this PC.

The dataset run's GPU implementation was built with CUDA 13.2, but this execution environment could not see the NVIDIA device. GPU timing rows therefore represent CPU emulation, as noted in `summary.md`.
